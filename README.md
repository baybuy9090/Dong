# 동업계 남성 컨템 브랜드 입점 현황

롯데·현대·신세계 남성 컨템포러리 브랜드 37종의 45개 지점 입점 현황을 매일 자동 수집하고, 월별 신규 입점·퇴점 변화와 상권·도면·뉴스를 웹 대시보드로 보여주는 도구입니다.

## 구조

- `crawler.js` — 크롤링 스크립트 (Node.js)
- `config.js` — 3사 지점 코드·고유 ID·표시명·상권·좌표와 브랜드 분류 공통 설정
- `.github/workflows/crawl.yml` — 매일 09:00(KST) 자동 실행 (수동 실행도 가능)
- `data.json` — 최신 크롤링 결과 (자동 생성/갱신됨)
- `history/YYYY-MM-DD.json` — 일별 결과 스냅샷, `history/index.json`은 보관 목록
- `monthly-archive.json` — 직전 월 마지막 정상 데이터와 비교한 월별 신규 입점·퇴점 아카이브
- `baseline.json` — 과거 2026-06 수기 스냅샷 보관용. 현재 변화 판정에는 사용하지 않음
- `review-decisions.json` — 신규·퇴점·오탐에 대한 사람의 영구 검토 결과
- `floor-crawler.js`, `floor-images.json` — 3사 층 도면과 층별 관리 브랜드 수집 결과. 공식 남성층과 현재 입점 데이터를 교차 검증하며, 현대는 공식 다비오 벡터 데이터를 `floor-maps/hyundai/`의 일반·강조 정적 SVG로 각각 변환해 화면에서 별표 강조를 켜고 끌 수 있음
- `brand-floor-index.json` — 브랜드 상세에서 정확한 지점·층 도면으로 이동하기 위한 인덱스
- `floor-history.json` — 층 추가·삭제, 브랜드 추가·삭제·층 이동, 도면 변경 이력과 현재 비교 서명
- `news-crawler.js`, `news.json` — 브랜드 뉴스와 사업 이벤트 분류 결과
- `index.html` — 대시보드 화면
- `tests/` — 점포 별칭, 브랜드 매칭, 수집 지연, 뉴스 이벤트 회귀 테스트

## 처음 설정하는 방법

1. **저장소 만들기**
   - GitHub에서 새 저장소 생성 (Public)
   - 저장소 전체 파일을 올리기

2. **GitHub Pages 켜기**
   - 저장소 → Settings → Pages
   - Source: "Deploy from a branch" → Branch: `main`, 폴더: `/ (root)` → Save
   - 잠시 후 `https://[사용자명].github.io/[저장소명]/` 에서 대시보드 확인 가능

3. **크롤링 최초 실행**
   - 저장소 → Actions 탭 → "브랜드 입점 크롤링 (매일)" 워크플로우 선택
   - "Run workflow" 버튼으로 수동 실행 (완료까지 몇 분 소요, GAS와 달리 6분 제한 없음)
   - 완료되면 `data.json`이 자동으로 커밋됨 → 대시보드 새로고침하면 반영

## 월별 신규 입점·퇴점 판정

- 매월 첫날 직전의 마지막 정상 스냅샷을 그 달의 비교 기준으로 사용합니다.
- 변화가 처음 감지되면 `신규 입점 재확인 중` 또는 `퇴점 재확인 중`으로 표시합니다.
- 다음 정상 수집에서도 같은 변화가 관찰되면 `이번 달 신규 입점` 또는 `이번 달 퇴점`으로 확정합니다.
- 월이 끝나면 해당 월의 마지막 정상 스냅샷을 기준으로 `monthly-archive.json`에 보관합니다. 기존 데이터가 있는 2026-08부터 아카이브합니다.
- 점포명은 표시명과 별개인 점포 코드 기반 고유 ID로 비교합니다. 롯데 `수원점`, `타임빌라스 수원`, `수원`은 모두 같은 `롯데-0349`로 처리합니다.
- 외부 사이트 오류나 0건 이상 응답은 변화로 처리하지 않고 직전 정상값을 유지합니다.

## 사람 검토 결과 반영

대시보드에서 `정상으로 이동` 또는 `삭제 확정`을 누르면 우선 현재 브라우저에 저장됩니다. 처리 내역에서 `review-decisions.json`을 내려받아 저장소의 같은 파일을 교체·커밋하면 다음 크롤링부터 모든 기기에 영구 적용됩니다.

## 이후 사용

- 입점 데이터는 매일 09:00(KST), 도면은 10:00(KST), 뉴스는 08:00(KST)에 자동 갱신됩니다.
- 급하게 다시 돌리고 싶으면 Actions 탭에서 "Run workflow"로 수동 실행 가능합니다.
- `index.html`을 수정하고 싶으면 그냥 파일을 고쳐서 커밋하면 됩니다 (배포 버전 갱신 절차가 따로 없습니다).
- 로컬 검증은 `npm test`, 문법 검사는 `npm run check`로 실행합니다.

## 알려진 한계

- 롯데 크롤링의 기본 `townCd`는 강남점 기준값이라, 별도 관이 있는 지점은 `LOTTE_EXTRA_TOWNS` 보정이 필요할 수 있습니다.
- "매출" 데이터는 각 사 홈페이지에 공개되어 있지 않아 자동 수집이 불가능합니다.
- 페이지 전체 텍스트에서 브랜드명을 찾는 방식이라, 실제 매장이 아닌 다른 영역(추천 브랜드 등)의 언급도 잡힐 수 있습니다.
